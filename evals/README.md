# 真实资料课程评测

这组评测分别检查资料读取、约束处理、内容与程序行为。结构校验通过不代表教学事实正确；未做学习者试学时，不报告教学效果或真实耗时已经通过。

## 固定输入与参考

- `cases/`：两项三课课程任务，以及预算不足、来源缺失两个边界任务。天数与每天分钟数从这里独立传给构建器。
- `reference/rubric-and-oracles.json`：在课程生成前固定的核心目标、参考计算和评分规则，不提供给课程生成代理。
- `source-manifest.json`：来源 URL、取回日期、快照类型和 SHA256。Python 官方 HTML 下载到本地 `sources/`，不进入 Git 或 skill 安装包。NIST 直连返回 403，官方页面已通过受支持 web 工具读取；`source-notes/` 仅保存核实的事实摘记，明确不冒充完整原文快照。
- `runs/`：保存实际独立代理生成的原始输出、输入与技能摘要 hash、程序报告和复核记录。模型部署标识不可见时填写 unavailable，不推断具体型号。

首次每个正向用例生成两次；原始输出保留，修订另存文件。重复生成用于观察差异，不视为具有统计代表性的模型评测。不同代理之间不共享参考答案或上一轮课程。

四次实际生成的原稿、构建版、报告与计算证据已经归档；两项边界响应位于 `boundary-runs/`。固定课程的独立核算可运行 `python3 evals/review_checks.py`；103条计算/关系检查通过的结论限于hash冻结的这四份原稿，不能用于自动认证新课程。初始读取时的完整skill快照未单独捕获，归档记录明确保留这一溯源限制，不把归档时hash当作生成时版本证据。

## 验收规则

事实与答案 30 分、来源可追溯 20 分、约束与预算 20 分、教学完整性 15 分、测验质量 15 分。85/100 是内部试运行线，并非科学认证。关键事实、单位、答案、核心目标覆盖、唯一正确选项、来源读取诚实性和不改用户硬约束是阻断项。

计算和短代码须独立核算，逐题核对选项与解释。另一个代理审阅只能提供辅助证据，不能替代原始来源或真人学习试验。没有真实试学时保留 `learner_trial: pending`、`time_feasibility: estimated`。

## 再运行

1. 阅读案例输入和该版本 skill；按来源 manifest 准备资料，检查实际读取范围。
2. 在隔离临时目录生成完整课程并保存原始计划、预算估计及生成报告。
3. 使用案例独立约束运行 `validate_plan.py` 和 `build_learning_site.py`，保存 stdout/stderr。
4. 用固定参考与原始来源逐项复核；记录缺陷与修订，不覆盖原始生成结果。
5. 对修订后的页面另做浏览器验收。程序结果、代理内容复核和真人试学分别报告。
