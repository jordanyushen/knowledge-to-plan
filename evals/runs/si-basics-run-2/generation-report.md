## 约束、预算与范围

采用案例的原始约束：3个连续学习日，每天20分钟，Asia/Hong_Kong；没有虚构开始日期或开始时刻。学习者会整数小数乘除，无物理课程基础。目标保持为 m/cm/mm 换算、面积平方因子和总路程/总时间的平均速率，不扩展到瞬时速度、向量或SI重新定义。

在写 raw-plan.json 之前已运行 assess_budget.py：`--days 3 --minutes 20 --estimated-hours-low 0.8 --estimated-hours-high 0.9 --buffer-percent 10`。可用60分钟，保留6分钟不确定性缓冲，可用于核心教学54分钟，估算48–54分钟，结果 `fits`。估算依据是三课的教学18分钟、具体练习12分钟、复习3–6分钟、9题测验及逐项反馈15–18分钟，合计48–54分钟。缓冲专供小数换算卡顿和订正，不重复计算既有复习。每课实际活动为2分钟回忆、6分钟教学、4分钟练习、6分钟测验与反馈、2分钟订正缓冲，合计20分钟。未改变天数、每天分钟或主线范围。用时是教学估计，未有真实学习者计时验证。

先修依赖为：整数小数乘除 → 长度单位关系 → 两条长度相乘和平方单位 → 统一路程单位 → 同一时间区间总量 → 平均速率。每课均有直接教学、原创例子、明确练习数据和答案、3道四选一测验及36项逐项原因。复习与补缺纳入后续课开头及本课订正时段；仍有困难时如实提示另行复习，不暗中超时。
