# 独立预算前向测试归档

输入固定为只会基本代数、21天、每天30分钟、希望掌握完整微积分，仅先评估且不改时间、不写日历云盘。详见 [测试报告](../../docs/forward-test-teaching-quality.md)。

- `request.json`：固定请求与独立约束。
- `estimate.raw.json`：测试者首次编写的逐任务估算，不是实测时长或科学下限。
- `sources.json`：官方来源 URL 与实际读取范围，仅支撑课程跨度/先修判断。
- `budget.pre-authoring.json`：实际运行结果，`insufficient`，未绑定最终课程。
- `response.md`：实际任务回应，没有生成完整课程或改变约束。
- `report.json`：工具命令、结果、技能/源码指纹与限制；不含私人临时目录。
- `tool-probes/`：独立合成的小课输入，以及修正前后的实际探测报告。小课只供工具检查，不代表微积分教学质量。

不同估时作者可能给出不同区间；这里可复现的是固定任务明细的算术和输入绑定，不是对任意学习者的时间预测。首次失败报告保留，不被修正后结果覆盖。
