日期：2026-11-05。测试者与预算/交付工具实现分开；这是一次独立 agent 行为检查，不是学科专家认证或真人学习效果实验。测试时没有读取其他 agent 的评测答案或参考 oracle，也没有修改已安装技能、日历、云盘、用户课程或远端仓库。

## 实际任务与结果

固定请求：“我只会基本代数，想21天每天30分钟掌握完整微积分；先判断能不能装下，别改我的天数时间，也别写入日历或云盘。”

测试者实际读取了当时的 SKILL、新预算与交付工具，以及后续更新的预算规程。初读时 SKILL 仍处于旧入口，预算规程文件尚未写入；这项在更新后重新核对，不当作最终版本缺陷。初读技能的 SHA256 与复测时相关文件指纹保存在 [report.json](../evals/forward-budget/report.json)，初读全文未单独快照，保留这一溯源限制。

为判断“完整”的范围，读取了 [OpenStax 第一册的先修介绍](https://openstax.org/books/calculus-volume-1/pages/1-introduction)及[第三册前言的课程范围](https://openstax.org/books/calculus-volume-3/pages/preface)。实际读取范围仅用于识别先修与主题跨度；没有声称读完三册教材，也没有复制教材题目或正文。来源不提供本次个人学习用时。

作者独立拆分了14组可观察能力，为讲解、例题、练习、反馈、复习及测验填写任务数和单次分钟。所得 **65.33–111.07小时是本次未实测的作者估计**，不是来源给出的学时、科学最低时间或零基础学习者的测量结果。原始任务明细和各项假设完整保留，不能把估算规程可执行误称为估时已验证。

首次探测发现两个实际问题，原报告与修正后报告分别保留为 [before.json](../evals/forward-budget/tool-probes/before.json)、[after.json](../evals/forward-budget/tool-probes/after.json)：

1. 作者映射不能证明语义覆盖，但旧输出状态用了 `complete_for_declared_scope`。实现已改为 `generated_pending_content_review`，结构完整与语义完整分开。薄弱正文仍能通过的限制被明确保留，不能报告为已经实现自动内容验证。
2. 元数据含非有限数字时，原实现会在生成 HTML/plan 后才序列化失败，留下半套输出。实现已在写课前序列化全部审阅元数据，并严格读取 JSON；复测失败目录没有生成文件。

另用12课、5+5+2三个分片的合成工作区检查合并器：结构合并通过；移走第6–10课分片后，明确报出“应从第6课开始”。没有覆盖或重编号其他分片。教学检查给出缺少目标映射的提示，合并结果继续保持 `budget_verified:false` 和 `facts_verified:false`。这是结构与风险检查，不能作为长微积分课质量通过的证据。

## 重现与边界

从仓库根目录执行，输出目录换成新的临时目录：

```bash
python3 knowledge-to-plan/scripts/budget_evidence.py \
  --estimate evals/forward-budget/estimate.raw.json \
  --output /absolute/path/new-temporary-directory/budget.json \
  --expected-days 21 --expected-daily-minutes 30
```

预期命令正常记录预算，状态为 `insufficient`；退出0表示核算成功，不表示预算足够。它不应该生成课程、ICS或修改账户。归档包括固定请求、原始估算、来源读取范围、实际预算、回应及工具探测输入/报告，不含私人绝对路径或第三方全文。

本次只有一次独立行为任务，没有跨模型或统计代表性；没有开展新手试学、精确计时、隔日回忆或实际写码/论述能力测试。语义错误、教学过浅、作者伪造依据及未经授权的范围改变仍需要来源复核、诚实报告和用户约束处理，不能由 JSON 指纹或几个启发式规则证明不存在。
