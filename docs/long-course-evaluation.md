# 窄范围长课工具评测

日期：2026-11-05。输入与原稿位于 [evals/long-course](../evals/long-course/fixture-input.json)。这是由作者agent编写的合成工具评测，不是某位真实学习者的课程需求，也不是独立模型生成实验、专家认证或学习效果试验。

## 范围选择与预算

原边界目标保留为“零基础掌握完整基础微积分”。本样本**显式选择更小目标并改变背景假设**，用于检查窄范围长课链路：已会基础代数，仅处理二次函数的平均/瞬时变化率、次数不超过2的多项式求导，以及使用给定原函数和基本定理计算简单定积分。幂函数原函数可含三次项，但不扩展为一般高次求导或证明训练。

不覆盖完整极限理论、三角/指数/对数函数、乘积/商/链式求导、换元与分部积分、广泛应用或大学考试保证。该合成范围选择不能作为替真实用户缩目标、补造基础或修改约束的授权。

保留 **21天、每天30分钟**。每课安排24分钟：讲解5、例题3、独立练习7、反馈订正3、检索复习3、测验3。任务估算区间为357–504分钟；总预算630分钟，额外储备15%后可用535.5分钟，因此本组作者假设在算术上为 `fits`。复习与订正已经进入任务估算，额外储备没有重复计入这两项。

估计依据、任务数量、先修假设和排除范围见 [estimate.json](../evals/long-course/estimate.json)，课程指纹绑定结果见 [budget.json](../evals/long-course/budget.json)。这些数字是可审查的作者假设，尚未经过目标背景学习者计时；`fits` 不等于已证明可以学会，也不要求学习者停留满预算分钟。

## 课程与来源

| 课次 | 主要任务 | 复核重点 |
|---|---|---|
| 1–5 | 函数值、变化量、正负区间平均变化率、二次差商、平均与瞬时区分 | 两种差不能错序；h趋近0不能直接除以0；严格二次函数的平均与起点导数关系 |
| 6–10 | 常数/直线/二次项逐项求导、导数函数与值、单点导数为零 | 系数和符号保留；单点为零不代表恒定 |
| 11–15 | 原函数、常数自由度、初值、常数累积、给定幂函数原函数与基本定理 | 定积分与原函数族区分；连续条件；上端点减下端点 |
| 16–21 | 有向与总面积、反向/拼接、点上率与区间净变化、负积分、查错与迁移 | 量与数值区分；符号与端点；选对运算 |

四个可观察目标在 [goal-map.json](../evals/long-course/goal-map.json) 映射至讲解、实际练习、题目和后续复习，ID与估算目标一致。每课至少一道四选一题，正确项位置随课次轮换；第2课开始跨课回顾。分片分别为1–5、6–10、11–15、16–20、21课，没有未生成占位。

本次用支持的网页工具实际读取以下官方节的相关规则和概念；只保存链接与定位，未将教材全文、原题或原图放入仓库：

- 平均差商、点上导数与瞬时变化率：[OpenStax §3.1](https://openstax.org/books/calculus-volume-1/pages/3-1-defining-the-derivative)。
- 常数、幂函数、和与常数倍求导：[OpenStax §3.3](https://openstax.org/books/calculus-volume-1/pages/3-3-differentiation-rules)。
- 定积分、有向面积、总面积与区间性质：[OpenStax §5.2](https://openstax.org/books/calculus-volume-1/pages/5-2-the-definite-integral)。
- 连续函数与原函数的端点求值规则：[OpenStax §5.3，基本定理第二部分](https://openstax.org/books/calculus-volume-1/pages/5-3-the-fundamental-theorem-of-calculus)。
- 基本积分与净变化关系：[OpenStax §5.4](https://openstax.org/books/calculus-volume-1/pages/5-4-integration-formulas-and-the-net-change-theorem)。

讲解、数字例子、题目和两幅SVG为本仓库原创。第2课割线图按横轴60像素/单位、纵轴15像素/单位绘制，说明两轴比例不同不能直接由屏幕倾角读斜率；第16课有向面积图双轴均100像素/单位。坐标和三角形面积单独复算，不因SVG合法就认为图文一致。

## 实际检查与证据边界

运行：

```bash
python3 evals/check_long_course.py
```

脚本检查输入文件hash与课程语义指纹，再在临时目录走完整合并与交付链路，结束后删除临时HTML，不把生成页面重复提交到Git。

已执行结果：

- 21课、5个分片完整合并；预算记录、四个目标映射与最终课程一致。
- 21道题的正确答案唯一，84个选项都有解释。
- [reference.json](../evals/long-course/reference.json) 的87条有理数计算记录全部通过，覆盖每课计分题、数值例子与具体练习；其中题目和例子有相同数值，不能把87条说成87种独立教学情境。
- 另有4条代数恒等关系与5处已审公式表达对应检查，共96条算术/公式检查；两幅SVG有13项坐标、关系和面积检查。
- 两项“可能需要图”的提示分别在第17、19课按位置复核：前者回顾已有有向面积图，后者通过代数符号和已有面积区分推理，无需重复绘制装饰图。依据见 [review.json](../evals/long-course/review.json)。
- 完整交付入口在临时目录生成HTML、计划和证据文件，保存 `generated_pending_content_review`、`facts_verified:false` 与估计耗时状态，没有把程序通过当成课程事实或学习效果认证。

有理数算法由作者另外手写，只读取明确的多项式系数和操作类型，不从课程文字生成或执行代码。它不能给任意新课程验真；自然语言含义、条件与教学适切性仍需另行审阅。独立内容审阅另见 [long-course-independent-review.md](long-course-independent-review.md)，不与作者侧核算混为一项。

## 首次问题与修订

独立审阅确实发现首版两处措辞错误，不能报告首次全部成功：

1. 第5课曾说严格二次函数的区间平均变化率和起点导数可能数值偶合。对非退化二次函数且端点不同，两者之差为二次系数乘端点差，不为零；现明确限定。
2. 第18课曾把点上变化率与区间净变化说成“不是同一数”。它们是不同量，但数值可能相同；现已更正。

首版完整语义计划保存在 [first-reviewed-plan.json](../evals/long-course/review-history/first-reviewed-plan.json)，首次缺陷记录保留于 [long-course-independent-first-findings.json](../evals/long-course-independent-first-findings.json)。修订后才重新绑定预算、目标映射、参考和输入hash；没有覆盖首版原稿冒充首次成功。

另在冻结前修正过第15课条件文本中的HTML实体：纯文本字段应写 `a<b`，不写会原样显示的 `a&lt;b`。公式与SVG的浏览器呈现证据由单独浏览器检查记录，算术检查不能替代视觉验收。

## 负向控制与仍未验证范围

脚本对内存副本植入5种缺陷并确认检测路径：

| 缺陷 | 发现路径 |
|---|---|
| 把所有正确项移到A，语义仍正确 | 教学启发式阻断答案位置恒定 |
| 首次显式复习拖到最后一课 | 教学启发式发出复习过晚提示 |
| 核心目标缺教学定位 | 目标覆盖检查阻断 |
| 把x²的原函数错写成x³/2 | 可信代数核算发现，再以不可豁免的内容缺陷阻断；不声称正则自动识别数学错误 |
| 割线图标注点偏离实际函数 | 独立图形坐标核对失败 |

这些内存变体不改冻结原稿。源文件变化会因hash不同拒绝沿用当前记录，修改后需重新审阅，不能只刷新校验值。

未做真人先修诊断、准确学习计时、隔日回忆或陌生迁移表现测试。单选订正不证明能独立解一般微积分题；本样本不支持“完整微积分在10.5小时内掌握”的结论。真实浏览器、打印与离线行为继续按各自实际记录报告。
