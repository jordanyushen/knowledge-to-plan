| 范围 | 本地行为 |

新入口为 `knowledge-to-plan/scripts/build_course.py`。它仍输出 `generated_pending_content_review`、`facts_verified:false`、`time_feasibility:estimated`。目标映射有定位并不证明实际讲解充分；通过结构和风险检查不能代替来源核对、独立复算或真人试学。

## 内容证据与发现

- [原微积分样课复核](calculus-review.md)：只读原稿，未复制全部私人课程或改写学习记录。全A、首次显式复习到第20课、范围过大可直接检查；D6点/割线和D12拐点标注的错误来自独立几何复算，不能冒充自动语义识别。
- [独立前向试跑](forward-test-teaching-quality.md)：保持21×30分钟，估算与来源范围分别保存。预算不足时不生成完整课程、日历或云端内容。试跑还发现并修复了“无内容复核仍声称完整”和“非有限元数据导致半套输出”两个问题。
- [长课评测](long-course-evaluation.md)：固定较窄目标、21课分片、来源定位与有理数核算。作者样本不等于模型基准；修订记录与首次失败分别保留。
- [长课独立复核](long-course-independent-review.md)：与样本编写分开的复核，记录实际读过与算过的范围。没有真人耗时或学习效果结论。

## 验证边界

本轮本机80项 Python 课程/预算/教学检查、7项发布工具测试与Node运行时检查通过；演示重建一致性、旧评测原稿和103项固定核算继续通过。技能通过 skill-creator 的结构验证。长课作者核算96项算术/公式、13项图形和5项负向控制通过；独立复核另有108项固定核算，覆盖21题、84个选项及两幅图。这些计数口径不同，不相加冒充独立题目数或统计认证。

新长课检查及独立复核已加入CI配置；本轮没有触发远端运行。本机实际执行原稿48项定点检查，结果表示预期缺陷成功复现，不表示原稿通过。

UI通过受支持的现有 Chrome，在独立 HTTP 夹具检查390/580/600/768/800/801/1024/1440px、展开目标及0→50→100%状态。不是用户原课程，也不是所有浏览器验证。16项浏览器用例已注册，本机没有由命令行启动 Playwright/Chrome；新增用例的远端 CI 尚未运行。`file://`、真实手机、Safari/Firefox和打印的实际范围分别记录，不从旧版 CI 成功推断本轮通过。

实际窄范围21课也通过桌面1440px/手机390px的定向HTTP检查：5→6、10→11、20→21导航，第2/14课MathML，第2/16课SVG；移动图示在自身容器滚动，页面未横向溢出。没有声称浏览器逐页验收21课。打印预览未能通过支持的操作打开，未改变用户打印设置或绕过访问限制，故本轮打印仍未验证。

## 仍在后续范围

- 新手真实耗时、迁移表现和长期学习效果；估时规程不能自动证明作者假设真实。
- 文史精读/开放论述与编程实作的题型、完成状态和 rubric；本轮仅收窄能力表述。
- 页内代码沙箱、内置云连接器、PWA、复杂行内公式结构扩展；当前安全 MathML 继续用于公式块，正文和选项仍为纯文本。
- 原微积分课程自身修订：本轮修的是生成技能和回归样本，没有擅自覆盖用户课件或重新计算其成绩。
